# Metadata của các bản gộp đã xóa

Ba thư mục dữ liệu gộp và ZIP tương ứng đã được xóa khỏi `runtime/` theo yêu cầu dọn dẹp. Các file nhỏ ở đây lưu quyết định tuyển chọn và quality gate để đọc lại lịch sử. Chúng không chứa ảnh gốc và không phải bộ dữ liệu sẵn sàng train. Bản nền còn dùng nằm ở `runtime/dfire_clean_v2/`; ZIP dự phòng là `runtime/dfire_clean_v2_complete.zip`.
